Non-UTF-8 files use the same banner: “Read-only: this file isn't UTF-8 text.”

Info · watcher limit (F-04)
File watching is limited on this system. Changes made in other apps show up within 30 s instead of instantly. To fix it, run:sudo sysctl fs.inotify.max_user_watches=524288

Shown once per launch when max_user_watches is too low or the watcher stops.
