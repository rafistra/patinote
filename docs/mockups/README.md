# Mockup Patinote

HTML statis. Buka langsung di browser **dari dalam repo** (jendela 1440×860, skala 100%); font dimuat dari `crates/patinote-app/assets/fonts/` lewat `fonts.css`, jadi tidak butuh internet. Isi catatan di dalamnya adalah contoh sintetis, tersedia juga sebagai vault di `fixtures/vault-mockup/`.

- `png/` berisi screenshot referensi setiap mockup, dipakai sebagai pembanding snapshot UI (lihat `CLAUDE.md` bagian 6).
- Daftar file, kebutuhan PRD yang diacu, dan semua nilai warna, huruf, serta ukuran ada di [`../design/0003-ui-design-system.md`](../design/0003-ui-design-system.md). Bila mockup dan dokumen itu berbeda, dokumen itu yang benar.
- `90-target-final-phase6.html` adalah gambaran tampilan akhir, bukan spesifikasi Gerbang 1.

File di folder ini hanya diubah pemilik, dengan mengekspor ulang dari kanvas desain.
