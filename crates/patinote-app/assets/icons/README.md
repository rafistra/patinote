# Icons

Line icons for banners, drawn on a 24×24 grid with a 2 px stroke, copied
from the paths in `docs/mockups/17-banners-and-messages.html`. The stroke is
black; the app colors each icon with a token through Iced's SVG color filter.

`logo.svg` is the Patinote mark from the bufferline of `docs/mockups/01-minimal.html`;
the welcome card (mockup 10) uses the same mark at `size.logo.large`.
