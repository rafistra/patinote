# Fonts

Bundled with Patinote so the app never scans system fonts (memory budget in `docs/PRD.md`).

| File | Family | Version | License |
| --- | --- | --- | --- |
| `Inter-*.ttf` | Inter | 4.1 (github.com/rsms/inter) | SIL OFL 1.1, see `Inter-OFL.txt` |
| `JetBrainsMono-*.ttf` | JetBrains Mono | 2.304 (github.com/JetBrains/JetBrainsMono) | SIL OFL 1.1, see `JetBrainsMono-OFL.txt` |

Only the weights the UI uses are included (see `docs/design/0003-ui-design-system.md`, section 4). `SHA256SUMS` lists the checksums of the files as downloaded. The mockups in `docs/mockups/` load these same files.
